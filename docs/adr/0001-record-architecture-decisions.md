# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-18

## Context

The project direction has already changed once (from a Crosshare fork to a standalone app), and the README and old proposal disagree with the code. Team members need one place to find what has been decided and why.

## Decision

Record significant design decisions as ADRs in `docs/adr/`, following the process in [README.md](README.md).

## Consequences

- Issues and PRs can link to the ADR that justifies them.
- Changing a decision requires a new ADR, which makes reversals visible.
